# Commit & Push Rules

- No `Co-Authored-By` line in any commit message. Plain message only (type: summary, optional body).
- No AI/assistant attribution footer of any kind (no "Generated with", no bot signatures) in commits or PR descriptions.
- Push only when explicitly asked.
- Commit messages: Conventional Commits style (`feat:`, `fix:`, `docs:`, `chore:`), subject line only unless a "why" needs a body.
